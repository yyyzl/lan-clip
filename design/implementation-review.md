# 实现与视觉验收

已确认方向：暖白、森林绿、鼠尾草绿，中文轻量工具。保留已批准的品牌行及「发到电脑」标题结构、设备行、等尺寸双按钮。首页不放 Wi-Fi、自动连接、同时发送等重复说明；配对页保留完成配对所必需的操作和地址信息。

发送文字打开空白输入框；系统粘贴由用户自行调用。图片通过相册选择并预览确认。两台电脑各自反馈写入结果。字体使用系统回退，界面遵守系统字号；320×640、1.5 倍字号已检查无溢出。

动效采用按钮按下反馈、Material 弹窗淡入和缩放、接收内容 180ms 切换，遵循减少动效设置。没有附录屏，不宣称独立评审已经验证动态效果。

独立视觉评审一轮：7/10（静态视觉），未见遮挡、裁切、文案歧义；差距集中于图标比例及通用组件辨识度。随后将主操作图标统一为 24px；保留系统线性图标和已批准品牌标记，不增添装饰。电脑图片预览按窗口可用高度约束，保留完整图片比例。
