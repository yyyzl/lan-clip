Android 手机发送文字或单张图片，Windows 与 Mac 接收后直接写入剪贴板。

- 手机点「发送文字」，输入或粘贴内容；点「发送图片」，选择图片并发送。
- 电脑点「添加手机」，手机选择电脑并输入完整配对码；只有一台待添加电脑时自动选中。
- 所有已配对电脑同时接收。关闭电脑窗口后仍在托盘或菜单栏接收。
- 三端使用统一图标，安卓支持自适应与主题图标。
- 自动发现优先使用安卓实际网段广播，无法取得网段信息时使用通用广播；提供查找超时反馈、重试和手动 IP 入口。

### 下载

- **Android**：通常选择 `Lan-Clip-Android-arm64-v8a.apk`。旧 32 位设备选择 `armeabi-v7a`，模拟器可用 `x86_64`。
- **Windows x64**：下载 ZIP，完整解压后运行 `lan_clip.exe`，保留同目录 DLL 和 data 文件夹。
- **Mac**：下载 universal ZIP，解压后将 `Lan Clip.app` 拖入「应用程序」，同时包含 Apple 芯片及 Intel 架构。需要 macOS 12 或更新版本。

所有安装包由 GitHub Actions 构建，附 SHA-256 校验文件。Android 使用固定发布签名；Windows 尚无发布者代码签名，Mac 使用本地签名、尚未 Apple 公证。系统可能要求在安全设置中确认打开。

若安装过此前的本地安卓测试包，需要先卸载，再安装本次发布版并重新配对。之后发布版沿用固定签名，可覆盖安装。

首次连接允许本地网络访问；Windows 防火墙允许专用网络。手动 IP 能连接而自动发现失败，说明网络可能过滤了 UDP 广播；配对码只验证身份，本身不包含 IP 地址。
